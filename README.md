# WhisperFlow - бесплатная локальная диктовка для Mac

Аналог [Wispr Flow](https://wisprflow.ai/), который я сделала себе сама с помощью
Claude Code. Зажимаешь **Option (⌥)** в любом приложении, говоришь, отпускаешь -
и через пару секунд готовый текст появляется там, где стоял курсор. Telegram,
браузер, заметки, почта - работает везде.

Главное отличие от Wispr Flow: **все происходит на твоем Mac**. Голос никуда
не отправляется, подписку платить не надо, интернет нужен только один раз -
скачать модели.

Как это работает под капотом:

1. **OpenAI Whisper** (модель large-v3-turbo через mlx-whisper, оптимизация под
   чипы Apple) превращает речь в текст - с пунктуацией, на русском, английском
   и еще 100 языках.
2. **Gemma 3** (локально через Ollama, по желанию) приглаживает результат:
   исправляет ослышки и грамматику, убирает «эээ» и повторы.

## Что нужно

- Mac на **Apple Silicon** (M1, M2, M3, M4) - на Intel и Windows не заработает;
- Python 3.10 или новее ([скачать](https://www.python.org/downloads/), если нет);
- ~2 ГБ на диске для модели распознавания (+3 ГБ, если захочешь авторедактуру);
- 15 минут на установку.

## Установка

1. Скачай проект: зеленая кнопка **Code → Download ZIP** (или `git clone`),
   распакуй в удобную папку.
2. Даблклик по **`install.command`**. Если Mac ругается на «неустановленного
   разработчика» - правый клик по файлу → Открыть. Скрипт создаст окружение
   и скачает модель (~1.6 ГБ), подожди несколько минут.
3. Даблклик по **`start.command`** - в меню-баре (справа наверху, рядом с
   часами) появится значок ⌛, а затем 🎤.
4. Выдай разрешения в Настройки → Конфиденциальность и безопасность
   (macOS предложит сама, либо добавь Терминал вручную):
   - **Микрофон** - записывать голос;
   - **Универсальный доступ** - вставлять текст;
   - **Мониторинг ввода** - слышать горячую клавишу.
5. Перезапусти: `stop.command`, потом `start.command`.
6. Открой Заметки, зажми Option, скажи фразу, отпусти. Магия!

### Авторедактура (по желанию, но советую)

Чтобы текст был не «как сказала», а «как написала бы», поставь Ollama и
маленькую локальную модель-редактора:

```bash
brew install ollama
brew services start ollama
ollama pull gemma3:4b
```

Все, WhisperFlow подхватит ее сам. Если Ollama нет - приложение просто
вставляет текст без редактуры, ничего не ломается.

### Автозапуск при включении Mac

Даблклик по `autostart.command` - и больше вообще ничего запускать не надо.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Зажать Option и говорить | Идет запись (значок 🔴) |
| Отпустить | Текст распознается (⏳) и вставляется |
| Коротко нажать Option | Запись «надолго», руки свободны |
| Нажать Option еще раз | Стоп, текст вставляется |
| Esc во время записи | Отмена без вставки |

Меню по клику на 🎤: скопировать последний текст, язык (авто/русский/
английский), авторедактура вкл/выкл, звуки вкл/выкл.

Настройки - в `config.json`: горячая клавиша, модель, язык, промпт редактора,
максимальная длина записи. После правки перезапусти приложение.

## Если что-то не работает

- **Значок есть, но Option не реагирует** - не выдан «Мониторинг ввода».
- **Записывает, но текст не вставляется** - не выдан «Универсальный доступ».
  Сам текст не потерялся: меню 🎤 → «Скопировать последний текст».
- **Вставляется пустота** - проверь разрешение на микрофон, говори ближе.
- Подробности всегда в `whisper_flow.log` рядом с приложением - покажи его
  своему AI-ассистенту, он разберется.
